# 🛍️ C# WPF Internet Shop

**Modern desktop internet shop built using C# and WPF**, designed for high performance and scalability with advanced backend tools.

---

## 🚀 Technologies Used

### 🖥️ Frontend

* **WPF (Windows Presentation Foundation)** – building modern Windows UI
* **MaterialDesign in XAML** – stylish and responsive design components

### 🔧 Backend

* **.NET Core** – core application logic
* **Redis** – used for:

  * Caching (boosts performance ×8)
  * Message brokering for background tasks
* **Prometheus** – monitoring and real-time metrics collection
* **ACID-compliant SQL** – ensures safe and consistent inventory updates
* **Supabase Storage** – cloud storage for product images
* **MS SQL** – local persistent storage
* **Dapper** – lightweight and efficient ORM for database access

---

## ⚙️ Features

* Fast and responsive product management interface
* Background workers for handling rating and inventory updates without blocking UI
* Scales to handle **1000+ users per second** with Redis + async messaging
* Safe data handling with ACID transactions
* Real-time backend analytics using Prometheus
